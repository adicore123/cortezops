# קורטז — מערכת תפעול פנימית

מערכת ניהול ליבואן אופניים וקורקינטים חשמליים: תיקי מכון התקנים עם ליקויים
ותיקונים (כולל מצב מדבקה עם תמונות לפני/אחרי), מאגר דגמים עם אישור פנימי,
מלאי חלפים עם תנועות, קריאות שירות מסוכנים ולוח בקרה — הכול בעברית RTL
במיתוג הרשמי של קורטז ורספונסיבי לנייד.

## הרצה מקומית

```bash
npm install
npm run dev        # http://localhost:3000
```

בהרצה הראשונה נטענים אוטומטית נתוני דוגמה (דגמי קורטז אמיתיים מהקטלוג,
תיקים, ליקוי מדבקה לדוגמה, חלפים וקריאות שירות).

**משתמשי דוגמה:**

| תפקיד | משתמש | סיסמה |
|---|---|---|
| מנהל מערכת | `admin` | `admin123` |
| צוות יבואן | `danny` | `danny123` |
| צוות (בלי עלויות יבואן) | `ronit` | `ronit123` |
| סוכן | `avi` | `avi123` |

> שנו סיסמאות בהגדרות → משתמשים לפני שימוש אמיתי.

## אחסון

הנתונים נשמרים כרשומות JSON וקבצים בתיקיית `data/` (לא נדרש מסד נתונים).
כתיבות אטומיות ומסונכרנות, וגיבוי ידני זמין בהגדרות → גיבוי.

## פריסה ב־Vercel

מערכת הקבצים ב־Vercel ארעית, ולכן הפרויקט כולל אדפטר אוטומטי (`src/lib/db/storage.ts`):
כשמוגדר `BLOB_READ_WRITE_TOKEN` הנתונים עוברים ל־**Vercel Blob** (פרטי). בלי הטוקן —
אחסון מקומי בדיסק. שימו לב לשלושה מנגנונים שנבנו במיוחד לסביבת ה־serverless:

- **כתיבה תחת נעילה מבוזרת** — בלוב נעילה עם TTL, כך שמופעי פונקציות שונים לא
  דורסים זה את כתיבותיו של זה (read→modify→write אטומי).
- **`cacheControlMaxAge: 0`** בכל כתיבה — ברירת המחדל של Blob היא שנה של מטמון CDN,
  מה שגורם לקריאות מהפונקציות לקבל גרסאות ישנות.
- **Read-your-writes** — מטמון קצר (10 שניות) של כתיבות אחרונות במופע, שמכסה את
    חלון אי־העקביות הקצר של האחסון המבוזר.

```bash
npm i -g vercel
vercel login
vercel link                                          # קישור הפרויקט
vercel blob create-store <שם> --access private --region fra1 --yes
# הטוקן נוסף אוטומטית למשתני הסביבה ול-.env.local
vercel --prod
```

הגדרות הפריסה ב־`vercel.json` (אזור `fra1` — הקרוב לישראל).

## מבנה עיקרי

```
src/lib/db/storage.ts   # אדפטר: דיסק מקומי / Vercel Blob (נעילות, גיבוי)
src/lib/db/store.ts     # אוספי JSON: קריאה/כתיבה סינכרונית, מזהים, מספור
src/lib/db/seed.ts      # נתוני דוגמה
src/lib/auth.ts         # סשנים, תפקידים והרשאות (נבדקות בשרת)
src/app/(shell)/        # הממשק: לוח בקרה, תיקים, דגמים, חלפים, שירות, הגדרות
src/app/print/          # סיכום תיק להדפסה + הדפסת מסמכים נבחרים
src/app/api/            # REST API
data/                   # רשומות JSON + uploads (זמן ריצה, מקומי בלבד)
```

## הרשאות

- **מנהל מערכת** — הכול, כולל משתמשים, הגדרות וגיבוי
- **צוות יבואן** — תיקים/מלאי/שירות לפי דגלים; `viewCosts` חושף עלות יבואן
- **סוכן** — פתיחת קריאות וצפייה בקריאות שלו בלבד

כל הגישה לרשומות ולקבצים נבדקת בצד השרת.
